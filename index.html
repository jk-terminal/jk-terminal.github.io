What broke along the way
  • Permission denied (publickey). I tested the SSH login before adding the public key to GitHub. The clue: it was refused without ever asking for the passphrase.
  • A login that hung in silence. GitHub accepted the key, then nothing. The desktop key agent was waiting on a passphrase prompt that never appeared. ssh -v showed the stage; bypassing the agent for that one host fixed it.
  • Repository not found. I pushed before creating the repository on GitHub. The remote address was right; there was nothing at it yet.
